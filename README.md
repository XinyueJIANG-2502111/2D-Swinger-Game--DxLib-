# Neon Swinger Game

DxLib と C++17 で制作された、2D ワイヤーアクションのプロトタイプです。マウスで地形へワイヤーを射出し、振り子運動や巻き取りを利用して移動しながら、フィールド上の赤いコアを集めます。

## ゲームの特徴

- ワイヤーの射出、接続、解除、巻き取りを使ったスイング移動
- 重力、空気抵抗、浮力、水中抵抗を組み合わせた簡易物理演算
- カメラ位置を基準に周辺チャンクを生成するプロシージャル地形
- 円と AABB によるプレイヤー衝突判定、およびレイキャストによるワイヤー接続判定
- 入水時の水しぶきと、ばねモデルによる波の伝播
- 移動軌跡、コア取得、ワイヤー、水中などのパーティクル／発光表現
- コアの収集数を表示するスコア欄と、Tab キーで折りたためる操作ガイド

## 操作方法

| 操作 | キー／ボタン | 動作 |
| --- | --- | --- |
| 左右移動・スイング加速 | `A` / `D` または `←` / `→` | 地上・空中・水中で左右に移動します。ワイヤー接続中は接線方向へ加速します。 |
| ワイヤー射出 | マウス左ボタン | カーソル方向へワイヤーを射出します。射程は最大 600 px です。 |
| ワイヤー解除 | マウス右ボタン | 接続中または飛行中のワイヤーを解除します。 |
| ワイヤー巻き取り | `W` または `↑` | 接続中のロープを短くします。 |
| ワイヤー繰り出し | `S` または `↓` | 接続中のロープを長くします。 |
| ジャンプ | `Space` | 地上・水中からジャンプします。ワイヤー接続中は解除しながら跳びます。 |
| 操作ガイド | `Tab` | 起動時はスコア欄の下に展開されています。折りたたむと `[Tab] Show controls` と表示されます。 |
| リスポーン | `R` | ゲームオーバー後にプレイヤー、水面、カメラ、マップ、スコアを初期化して再開します。 |
| 終了 | `Esc` | ゲームオーバー画面でゲームを終了します。 |

プレイヤーからマウスカーソルの方向に伸びる照準ガイドが水色なら、射程内に接続可能な地形があります。灰色なら、射程内に対象がありません。

## ゲームオーバー

水中で操作入力がない状態が続くと、5 秒後から浮力が徐々に低下し、10 秒でゲームオーバーになります。操作を再開するか水から出ると、無入力時間と浮力が元に戻ります。

## 動作環境

- Windows
- Visual Studio 2019 以降（「C++ によるデスクトップ開発」、MSVC と Windows SDK）
- CMake 3.16 以降（以下の Visual Studio 2022 向けコマンドには 3.21 以降が必要）
- C++17
- [DxLib](https://dxlib.xsrv.jp/) の Visual C++ 用パッケージ

## セットアップ

DxLib の Visual C++ 用パッケージを別途用意してください。既定では CMake が次のフォルダーを参照します。

```text
C:\DxLib_VC\プロジェクトに追加すべきファイル_VC用
```

このフォルダーに `DxLib.h` と、ビルド対象に対応する `.lib` ファイル一式があることを確認してください。CMake は同じフォルダーをヘッダーとライブラリの検索先に設定します。

## ビルド方法

プロジェクト直下で次のコマンドを実行します。以下は Visual Studio 2022 で x64 の Release ビルドを作成する例です。

```powershell
cmake -S . -B build/x64 -G "Visual Studio 17 2022" -A x64
cmake --build build/x64 --config Release
.\build\x64\Release\NeonSwingerGame.exe
```

DxLib を別の場所に置く場合は、構成時に `DXLIB_DIR` を指定します。指定したパスはビルドフォルダーの CMake キャッシュに保存されます。

```powershell
cmake -S . -B build/x64 -G "Visual Studio 17 2022" -A x64 "-DDXLIB_DIR:PATH=D:/Libraries/DxLib_VC/プロジェクトに追加すべきファイル_VC用"
```

32 bit 版をビルドする場合は、別のビルドフォルダーを使い、`-B build/x86 -A Win32` を指定してください。Visual Studio 2019 を使う場合のジェネレーターは `"Visual Studio 16 2019"` です。

### リソースについて

プロジェクト直下に `resources/` が存在する場合、ビルド後に実行ファイルと同じ出力先へ自動的にコピーされます。現時点の描画は DxLib の図形描画 API を中心に構成されているため、画像素材がなくてもソース上の主要な表現は動作します。

## プロジェクト構成

| ファイル | 役割 |
| --- | --- |
| `src/Main.cpp` | 初期化、入力、ゲームループ、スコア、ゲームオーバー、描画順序を管理します。 |
| `src/Player.*` | プレイヤーの移動、ジャンプ、ワイヤー、衝突、水中挙動、リスポーン時の状態初期化を実装します。 |
| `src/Terrain.*` | チャンクの生成と破棄、コア配置、レイキャスト、衝突判定、取得エフェクトを管理します。 |
| `src/Water.*` | 水面のばねシミュレーション、水しぶき、水中エフェクトを実装します。 |
| `src/Camera.hpp` | プレイヤー追従とワールド座標から画面座標への変換を行います。 |
| `src/Vector.hpp` | 2D ベクトルの基本演算を提供します。 |
| `src/ControlsGuide.*` | 操作ガイドの描画と Tab キーによる展開・折りたたみを管理します。 |
| `src/HudPanel.hpp` | スコア欄と操作ガイドの半透明パネルを描画します。 |
| `CMakeLists.txt` | ソース収集と、外部の DxLib を使う MSVC ビルドを設定します。 |

## 実装の概要

### ワイヤー

ワイヤーには `None`、`Flying`、`Pinned` の 3 状態があります。射出後はフレーム間の移動区間に対して地形とのレイキャストを行い、命中すると接続状態へ移行します。接続中はロープ方向への速度成分を除去して長さを制約し、左右入力を接線方向の力として加えることで振り子運動を作っています。

### 地形生成

ワールドを 400 px 四方のチャンクに分割し、カメラを中心に縦横 2 チャンクの範囲を読み込みます。縦横いずれかの距離が 4 チャンクを超えると、所属する障害物とコアをまとめて破棄します。チャンク座標から決まる独立した乱数を使うため、戻ったときは同じ配置が再生成されます。初期足場は常に残ります。

### 移動と衝突

移動距離に応じて 1 フレームの移動を複数回に分け、各ステップの直後に衝突を補正します。プレイヤーの直下を調べることで、足場に触れた状態でも接地を維持します。

### 水面

画面幅に 81 個の点を置き、それぞれをばねとして更新します。プレイヤーの下端が水面に触れると入水を判定し、入水速度に応じて水しぶきと波を発生させます。浮力はプレイヤーの直径のうち水面下にある割合に応じて変わります。

## 現在の仕様・制約

- 画面サイズは `800 × 600`、ウィンドウモード固定です。
- ゲームパッド操作、設定画面、音声、セーブ機能は未実装です。
- 終了キーは通常プレイ中ではなく、ゲームオーバー画面でのみ処理されます。
- 自動テストは用意されていません。
- ライセンスは明記されていません。再配布や利用条件を定める場合は、プロジェクト本体と DxLib のライセンスを確認してください。

## 開発時の注意

- 新しい `.cpp`、`.hpp`、`.h` は `src/` 以下に置くと CMake が自動的に対象へ追加します。
- 物理更新にはデルタタイムを使用し、1 フレーム最大 `0.05` 秒に制限しています。
- 実行ファイルから相対パスでリソースを読む場合は、実行ファイルの出力フォルダーを作業ディレクトリにしてください。
